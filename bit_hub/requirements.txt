# This is the fast local dev/test environment: FastAPI + webrtcvad run
# fine here. openWakeWord is deliberately NOT listed — it depends on
# tflite-runtime, which has no compatible wheel for Linux cp312. Running
# `bit_hub/backend/main.py` from this venv works end-to-end except that
# WakeWordDetector.load() will log a warning and stay disabled (no
# openwakeword to import). That's expected: use bit-voice:mark1 (built
# from Dockerfile.voice, Python 3.11) to run the Hub with a working wake
# word.

# install command), independent of the target Python version. Verified
# locally on 2026-09-18 — do not bump without re-testing `pip install
# webrtcvad` under the new pin.
