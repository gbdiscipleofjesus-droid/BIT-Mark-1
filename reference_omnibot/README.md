# reference_omnibot

The dossier lists this directory as a local reference copy of
[nazirlouis/OmniBot](https://github.com/nazirlouis/OmniBot), kept around
to compare BIT Hub's patterns (WebSocket protocol, wake word/VAD in the
Hub, follow-up window, persona-as-files) against the project it was
architecturally inspired by.

It isn't populated here: `nazirlouis/OmniBot` is outside this session's
GitHub access scope (only `gbdiscipleofjesus-droid/BIT-Mark-1` and
`gbdiscipleofjesus-droid/pygame` are in scope), so nothing was cloned or
fabricated into this folder.

To restore it: `git clone https://github.com/nazirlouis/OmniBot
reference_omnibot` (then keep it out of BIT's own git history — add it
to `.gitignore` or track it as a submodule, since it's a third-party
reference, not BIT's own code).
